# happytravel

Веб-приложение для совместных путешествий: пользователь создаёт поездку, приглашает друзей по ссылке или коду, участники вместе составляют план и бюджет и общаются в общем чате поездки.

Данные демонстрационные (`frontend/src/data/mockData.ts`), изменения хранятся в памяти браузера до перезагрузки страницы.

## Пользовательские сценарии

1. **Создание поездки.** Пользователь заполняет форму: название, обложка, направление, даты, число участников, бюджет, теги, описание.
2. **Приглашение.** Участник отправляет друзьям ссылку `/join/<код>` или код. Друг открывает ссылку или вводит код в «У меня есть код» и присоединяется.
3. **План.** Участники добавляют пункты программы по дням и отмечают выполненные.
4. **Бюджет.** Участники добавляют расходы, видят потраченную сумму, разбивку по категориям и кто кому должен.
5. **Чат.** Участники общаются в чате поездки.
6. **Мои поездки.** Пользователь видит предстоящие, организованные и завершённые поездки. Организатор может завершить или удалить поездку.
7. **Профиль.** Пользователь редактирует имя, город и информацию о себе.

## Экраны

| Экран | Адрес | Содержимое |
|-------|-------|------------|
| Вход / регистрация | `/login` | Форма входа и регистрации |
| Мои поездки | `/` | Поездки в виде круглых обложек, фильтр по вкладкам, ввод кода приглашения |
| Создание поездки | `/trips/new` | Форма с выбором обложки и проверкой полей |
| Приглашение | `/join/:code` | Информация о поездке, кнопка «Присоединиться» |
| Поездка — обзор | `/trips/:id` | Описание, бюджет на человека, участники |
| Поездка — план | `/trips/:id/plan` | Программа по дням |
| Поездка — бюджет | `/trips/:id/budget` | Расходы, категории, баланс участников |
| Поездка — чат | `/trips/:id/chat` | Сообщения участников |
| Профиль | `/profile` | Данные пользователя и статистика |
| 404 | любой неизвестный адрес | Сообщение и ссылка на главную |

Скриншоты экранов — в [`docs/screenshots`](docs/screenshots).

## Стек

- React 19, TypeScript, Vite
- MUI (Material UI) и `@mui/icons-material` — библиотека UI-компонентов
- React Router — клиентская маршрутизация

Оформление задаётся в `frontend/src/theme.ts`: палитра «матча с клубникой», шрифт Comfortaa (Google Fonts).

## Запуск frontend

Требуется Node.js 20 или новее.

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

| Команда | Назначение |
|---------|------------|
| `npm run dev` | Сервер разработки |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run preview` | Просмотр собранной версии |

Переменные окружения не требуются.
